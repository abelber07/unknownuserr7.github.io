Planificació de carrera en desenvolupament de software

A

Sortida Professional DAW/DAM

Desenvolupador Full Stack (DAW/DAM)

Especialitzat en creació de software per a web, dispositius mòbils i escriptori

1. Definició de la Feina

Professional que dissenya, desenvolupa i manté aplicacions informàtiques tant per a web com per a múltiples plataformes (Android, iOS, Windows, Linux) utilitzant tecnologies com Java, JavaScript, Kotlin, Swift, React Native, Flutter, etc.

2. Tasques Principals

  • Analitzar requisits del client/projecte
  • Dissenyar arquitectura de software
  • Programar codi seguint estàndards
  • Provar i depurar aplicacions
  • Documentar el codi i processos
  • Mantenir i actualitzar aplicacions
  • Col·laborar en equip amb metodologies àgils
  • Integrar APIs i serveis web

3. Competències Necessàries

  • Tècniques: Programació (Java, JavaScript, Kotlin, Swift), bases de dades, APIs, Git
  • Metodològiques: Scrum, Kanban, DevOps
  • Personals: Resolució de problemes, treball en equip, aprenentatge continu
  • Idiomes: Anglès tècnic (imprescindible)
  • Específiques: UX/UI bàsic, seguretat informàtica, patrons de disseny
